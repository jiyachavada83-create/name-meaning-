NAME MEANING FINDER 🌸
======================

Files:
- index.html  : Website structure
- style.css   : Pink floral responsive design
- script.js   : Name lookup, language switcher, popular names, dark mode

RUN ON YOUR LAPTOP
1. Extract the ZIP folder.
2. Open index.html in Chrome.
3. Search for Jiya or tap a popular name.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in or create a GitHub account at https://github.com/
2. Click the + button, then New repository.
3. Name the repository: name-meaning-finder
4. Set it to Public and create the repository.
5. Click Add file > Upload files.
6. Upload index.html, style.css, and script.js (upload the files themselves, not just the ZIP).
7. Click Commit changes.
8. Open Settings > Pages.
9. Under Build and deployment, choose Deploy from a branch.
10. Choose branch main and folder /(root), then Save.
11. Wait a minute or two. The Pages section will show your website URL.

NOTES
- This is a static website; it does not need a server or database.
- The included name collection is small and offline. Add more entries in the nameData object in script.js.
- Names can have multiple meanings depending on language and culture. Personality text is for fun, not a scientific claim.
- Google Fonts requires internet; the website uses fallback fonts if unavailable.
